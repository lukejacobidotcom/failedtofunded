Behaviour spec

Element
An <a> styled as a switch, not a checkbox: it navigates, so it is a link. aria-label="Switch to MyFundedPerps, trade crypto and stocks".
Destination
https://myfundedperpetuals.com with utm_source, utm_medium=referral, utm_campaign=perps_launch, utm_content=header-switch. One constant; change it in one place.
Click
Prevent default, slide the knob to the far end over 420ms, add .go, then set location.href. Modifier-clicks and middle-clicks fall through so open-in-new-tab still works.
Hover
Knob translateX(10px), seat outline brightens, arrow translateX(3px), border brightens and the green glow comes on. 200ms. The seat outline is always visible; the glow is hover-only.
Ticker
Illustrative prices in this build. On the real site, feed it from the Perps price API; BTC already ticks every 1.5s to show the hook.
Cube
cube.fundingperpetuals.com/cube-512-30-v1.webm, matted on black, composited with mix-blend-mode: screen so no alpha channel is needed. Muted, looped, plays inline.
Breakpoints
Ticker hidden below 1190px. Labels hidden and the cube shrinks to 34px at 520px and below. Header gap is 16px; nav items are white-space: nowrap so the nav can never wrap to make room.
Reduced motion
No ticker scroll, no slide on click. The cube holds a frame at 0.9s.
